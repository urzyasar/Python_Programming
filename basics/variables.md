# ✅ **Inside each markdown file — Use my 3–part structure**

Use this simple structure for every concept:

### **1. Concept**
Short 2–3 lines explanation.

### **2. When to use**
Real-world use case.

### **3. Code Example**
One or more clean examples written inside **triple backticks**.
